# MANEF AI module foundation

**Scope:** Versioned integration metadata and offline conformance checks for this product.
**Assumes:** Node 22.13+ for the generated checker; native runtime, authorization and configuration remain owned by this repository.

Run `node .manef/_generated/check-module.mjs` from the repository root. The checker validates the descriptor and existing layout paths; it does not run declared commands or verify live readiness.

Shared config allows secret references only. Product adapters must authenticate and authorize every call, resolve their own credentials, and enforce their own tenant boundaries. Capability declarations grant no execution authority.

Artifacts are generated by the MANEF AI integration repository. Compare foundation.lock.json hashes before adoption. Native tests and lockfiles stay authoritative. Update by reviewing a new version, never by replacing native config.
